Bank Marketing Predictor

Captura las características de un cliente y estima la probabilidad de que contrate un depósito a plazo. La predicción se ejecuta en la API, no en el frontend.

Frontend → POST /predict → Pipeline → Modelo → Resultado

¿Qué significa la probabilidad?

Es la probabilidad estimada por el modelo para la clase yes. No es una certeza ni una garantía de contratación.
